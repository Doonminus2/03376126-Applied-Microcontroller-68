ESP-IDF v6 FreeRTOS

สถาปัตยกรรม C++ OOP แบบ Bottom-Up • DS1307 RTC • SSD1306 OLED • Wi-Fi NTP

SSID: iotexpo
RTC: DS1307 (0x68)

วิธีออกแบบ OOP แบบ Modular และ Bottom-Up

สร้าง Hardware Abstraction Layer (HAL คือชั้นที่ซ่อนรายละเอียดฮาร์ดแวร์) ทีละชั้น ขึ้นไปจนถึงระบบ FreeRTOS (ระบบที่ให้ทำหลายงานพร้อมกัน)

โปรเจกต์นี้ออกแบบแบบ Bottom-Up Object-Oriented (เริ่มจากชิ้นเล็กสุดแล้วต่อขึ้นไป เขียนโค้ดเป็นก้อน object) สำหรับ ESP-IDF v6 (ชุดพัฒนาโปรแกรมของ ESP32) ตัว driver (โค้ดที่คุมฮาร์ดแวร์) แต่ละตัวสร้างและ unit test แยกกัน ไม่ต้องรอ logic ชั้นบน ตัวฮาร์ดแวร์ ได้แก่ I2C bus (สายสื่อสารระหว่างชิป 2 เส้น), DS1307 RTC (ชิปนาฬิกาที่เดินต่อได้แม้ไม่มีไฟหลัก), จอ SSD1306 OLED (จอเล็กที่แต่ละจุดเรืองแสงเอง) และปุ่มที่ debounce แล้ว (กันปุ่มเด้ง) ถูกแยกออกจากตัวทำ logic (TimeManager, AlarmEngine, StopwatchEngine) ผ่าน C++ interface กับของใช้ FreeRTOS ที่ thread-safe คือ queue (คิวส่งข้อมูลระหว่าง task หรืองานย่อย), mutex (กุญแจที่ให้ task ใช้บัสได้ทีละตัว) และ event group (ธงบอกเหตุการณ์ให้ task)

Spiral 1

ชั้น HAL และบัส

I2CBus driver ที่ thread-safe (หลาย task ใช้พร้อมกันได้ปลอดภัย), ตัวแปลง BCD (เลขฐานสิบที่เก็บแบบ 4 บิตต่อหลัก) จาก register ของ DS1307 และ driver buffer จอ SSD1306 128x64

สถานะ: ผ่านแล้ว
Spiral 2

ระบบเวลา

TimeManager (class ที่รวมเรื่องเวลาไว้ที่เดียว), driver Wi-Fi แบบ Station (ต่อเข้า router), ตัวซิงก์เวลา SNTP (ขอเวลาจริงจากอินเทอร์เน็ต) และ logic สำรองไปใช้ RTC เมื่อเน็ตหลุด

สถานะ: ผ่านแล้ว
Spiral 3

ระบบรับปุ่มและ UI

ระบบกันปุ่มเด้งผ่าน GPIO (ขาอินพุต/เอาต์พุตของชิป) และ ISR (ฟังก์ชันที่ทำงานทันทีเมื่อเกิด interrupt) แยกกดสั้น/กดค้างได้ และ task วาดภาพลงจอ OLED

สถานะ: ผ่านแล้ว
Spiral 4

ตัวทำ logic หลัก

AlarmEngine (เทียบเวลาปลุก) กับ driver บัซเซอร์ piezo (ตัวส่งเสียงปี๊บ) และ StopwatchEngine ที่จับเวลา lap ได้แม่น

สถานะ: ผ่านแล้ว
Spiral 5

รวมเข้ากับ FreeRTOS

ซิงก์หลาย task, ส่ง event ผ่าน queue, ใช้ mutex กันแย่งใช้บัส และเริ่มระบบใน app_main

สถานะ: ผ่านแล้ว

แผนภาพชั้นของ component

ดูว่าซอฟต์แวร์แยกเป็นชั้นอย่างไร ตั้งแต่ register ของฮาร์ดแวร์ขึ้นไปถึง task ของแอป

แผนผังวงจรฮาร์ดแวร์ ESP32

แผนที่การต่ออุปกรณ์ แสดงขาของ ESP32, DS1307 RTC, จอ SSD1306, สวิตช์ และบัซเซอร์

สเปกการทำหลายงานของ FreeRTOS

ชื่อ Task Priority (ลำดับความสำคัญ) Stack Size (หน่วยความจำของ task) Core (แกน CPU) ตัวกระตุ้น / คาบเวลา หน้าที่
vTaskClockDisplay 3 (กลาง) 4096 B Core 1 ทุก 100 ms วาดโหมดที่ใช้อยู่ (เวลา, ปลุก, จับเวลา) ลง buffer ของจอ SSD1306 แล้วส่งภาพออกทาง I2C
vTaskButtonHandler 5 (สูง) 3072 B Core 0 Event จาก ISR Queue รับการกดปุ่มที่กันเด้งแล้ว ตรวจจับการกดค้าง และสลับโหมดของนาฬิกา
vTaskAlarmCheck 4 (ค่อนข้างสูง) 2048 B Core 1 ทุก 1000 ms เทียบเวลาจาก DS1307 กับเวลาปลุกที่ตั้งไว้ ถ้าตรงก็สั่ง PWM (สัญญาณเปิด-ปิดเร็ว ๆ ใช้คุมเสียง) ผ่าน LEDC ให้ piezo buzzer ร้อง
vTaskNTPSync 1 (ต่ำ) 6144 B Core 0 ทุก 3600 s ต่อ Wi-Fi SSID (ชื่อเครือข่าย) 'iotexpo' ขอเวลาจาก pool.ntp.org ปรับเวลาระบบแบบ POSIX และเขียนเวลาใหม่ลง register ของ DS1307
